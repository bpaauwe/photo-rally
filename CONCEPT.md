Photo Rally is a web application to help design photo rallys

A photo rally is a type of gimick rally where the participants
are given a route and a set of photos. 

As they follow the route, they will encounter the objects in
the photos. When they spot one of the objects, they note their
mileage.

The participants are scored by how close they come to matching
the rally master's mileage for those objects.

The route is a numbered set of instructions with mileages. 
There are also the lines with mileages for each object. These
lines are hidden on the participants route sheet.

The score sheet has a place for the participant to write in
the mileage at which they found the object. Also they write
in a mileage at a know marker so that an odometer correction
factor can be calculated and applied to their mileages so
they match the official mileages.

With a web app that tracks participants, the app could present
the list of objects and the participants simply mark each one
when they find it. The app can use GPS to mark the location and
compare with official. This would elimiate having to calculate
scores at the end but does require a smart phone to run the app.

The instructions could include a QR code that takes the participant
to the website for the event. They enter thier name and car #.
App then presents a list of objects with a checkbox. When they
check the box, the GPS coordinats are fed back to the app.

Rally master version has the same thing, but when the check box
is checked, the official coordinates are feed into the app. The
rally master version would list the objects in order with mileages.

Needs a database to store events and results.

App has multiple modes:

1. Create route / print route
2. Event setup to get GPS coordinates for objects
3. Run event
4. Scoring (both for RM and participants?)


Selfie Rally variation

In this type of event, the participants are given a written
description of objects they'll see along the route. They need
to take a selfie that contains one or more of the team members
and the object. This is probably more like a scavenger hunt
gimick rally.

They are scored based on how many of the objects they collect
selfies for.


Question and Answer Rally

A more puzzle-y method of scoring, Q&A rallyes ask questions
between instructions (which may be just as gimmicked as those
instructions) that must be answered before moving on to the next
steps. Commonly, questions will either be selected so that
there's correct and incorrect answers depending on the route
taken, or so that questions either will or will not be answered
at all, depending on whether it's even possible to find an
answer for them.

Hare and Hound

Written route instructions with decision points at intersections.
Partipants may have to "guess" which direction to go. The 
correct direction will be confirmed by some type of marker/sign
a couple hundred feet down the road.

Could there be a variation of this where a "clue" is provided
by something prior to the decision point. Possibly in the form
of a question and the answer indicates the direction to go.

For example:

RI 1 - turn right on 1st street
RI 2 - count stop signs
T intersection decision point - Left for even counts, right for odd
RI 3 - left 1st opp

Or is this just a variation of a Q&A rally


Poker run / scrabble scramble

May be able to do some variation of a virtual course marker event
where cards/tiles are assigned when the car is near a checkpoint.
The web app keeps track of what cards/tiles have been assigned
to each car. For poker, each car's hand could be then be used
to score the event. Scrable is a bit different since the
participants really need to create words for points with
the tiles.
