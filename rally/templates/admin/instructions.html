Format reference

One line per instruction, fields separated by |:

mileage | instruction | note

  • mileage is the cumulative odometer reading. Leave it blank while the route is still being measured. Sheets show it to 1/100 mile.
  • note is optional and organizer-only. It prints only on the organizer copy.
  • NOTE | text adds a line with no number or mileage.
  • **bold**, *italic*, ***both***; \n starts a new line.
  • Optional header lines before the first instruction: Title: Subtitle: Date:
  • Lines starting with # are ignored. Section headers like [RALLY] are ignored.
  • Files from the TSD sheet tool load as long as the lines are plain mileage | instruction. Speed, pause and OUTPOINT lines aren't used here.
